# DELIVIO FASHION

Premium streetwear storefront built with Next.js 15.

## Netlify deployment

- Build command: `npm run build`
- Publish directory: `.next`
- Node.js: 20 or newer

Netlify's Next.js Runtime handles routing and server features. The shop currently displays product design previews only; live checkout, payment providers, product catalogue and fulfilment must be connected and tested before accepting orders.

## Local development

```bash
npm install
npm run dev
```
